# 데이터 출처 기록

## 사용 데이터

- 데이터명: 데이콘 청와대 청원 분류 경진대회 데이터
- 출처: https://dacon.io/competitions/open/235597/data
- 다운로드 날짜: 2026-05-22
- 저장 위치: `data/raw/train.csv`, `data/raw/test.csv`
- Git 관리 여부: 원본 CSV는 `.gitignore`에 의해 커밋 제외

## 데이터 구성

### `train.csv`

- 행 수: 40,000
- 컬럼: `index`, `category`, `data`
- 용도: 모델 학습, 검증, 테스트 분할에 사용

### `test.csv`

- 행 수: 5,000
- 컬럼: `index`, `data`
- 용도: 최종 추론 또는 제출 형식 검증에 사용

## 라벨 정의

| 라벨 | 카테고리 |
| --- | --- |
| 0 | 인권/성평등 |
| 1 | 문화/예술/체육/언론 |
| 2 | 육아/교육 |

## 선택 이유

- 프로젝트 목표인 국민청원 장문 텍스트 카테고리 분류와 직접 일치한다.
- 이미 3개 카테고리 라벨이 제공되어 베이스라인 모델과 KoBERT 모델의 성능 비교가 명확하다.
- 데이터 규모가 로컬 환경에서 EDA, 전처리, 모델링을 수행하기에 적절하다.
- 데이콘 규칙상 공공 데이터와 사전학습 모델 활용이 허용되므로, KoBERT 기반 실험을 보고서에 설명하기 좋다.

## 보조 후보

- Korpora `korean_petitions`: 2017.08 ~ 2019.03 청와대 청원 데이터
- `lovit/petitions_archive`: 월별 청와대 국민청원 아카이브

보조 후보는 데이터 규모 확장이나 추가 분석이 필요할 때만 사용한다. 본 프로젝트의 기본 학습 데이터는 데이콘 분류 데이터로 고정한다.
