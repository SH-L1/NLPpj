# NESO 원본 데이터 수집 기록

## 출처와 범위

- 공급자: National Energy System Operator(NESO)
- 데이터셋: [Historic Demand Data](https://www.neso.energy/data-portal/historic-demand-data)
- 공식 메타데이터 API: <https://api.neso.energy/api/3/action/package_show?id=historic-demand-data>
- 라이선스: [NESO Open Data Licence](https://www.neso.energy/data-portal/ngeso-open-licence)
- 수집일: 2026-11-24(한국 시간). 파일별 상세 UTC 수집 시각은 `download_manifest.json` 참조.
- 지역: Great Britain(잉글랜드·스코틀랜드·웨일스). 북아일랜드를 포함한 영국 전체를 뜻하지 않습니다.
- 대상 기간: 2022-01-01 ~ 2025-12-31. 2026년 부분 자료는 이번 수집에서 제외했습니다.
- 형태: 연도별 CSV 원본을 바이트 그대로 저장했습니다. 삭제·보간·표준화·컬럼 통합은 수행하지 않았습니다.

NESO는 자료를 사후 수정할 수 있다고 안내합니다. 재현에 사용하는 스냅샷을 구분하기 위해 파일별 SHA256, 바이트 수, URL, 리소스 ID와 공급자 수정 시각을 기록했습니다.

최종 평가 연도의 확인은 파일 구조와 기본 품질 검사에 한정했습니다. 모델·변수 선택과 성능 비교는 학습·검증 자료에서 진행합니다.

## 기본 변수

| 컬럼 | 의미 | 사용 방침 |
| --- | --- | --- |
| `SETTLEMENT_DATE` | 현지 정산 날짜 | 정산 구간과 결합하여 시간축 구성 |
| `SETTLEMENT_PERIOD` | 해당 날짜의 30분 정산 구간 번호 | 서머타임을 반영하여 해석 |
| `ND` | National Demand, MW | 다음 구간의 예측 대상이며 과거 값은 입력 후보 |
| `TSD` | Transmission System Demand, MW | ND와 다른 정의의 지표로 혼동 금지 |
| `EMBEDDED_WIND_GENERATION` | 추정 분산형 풍력 발전량 | 필요할 때 과거 관측값만 입력 후보로 검토 |
| `EMBEDDED_SOLAR_GENERATION` | 추정 분산형 태양광 발전량 | 필요할 때 과거 관측값만 입력 후보로 검토 |

ND는 계량된 발전량의 합에서 발전소 자체 소비, 수력 양수 펌핑, 연계선 수출 등에 필요한 발전량을 제외한 NESO의 수요 지표입니다. 가정용 소비만을 뜻하거나 모든 최종소비를 그대로 측정한 값이라고 해석하지 않습니다. 단위는 전력인 MW이며 에너지량인 MWh와 구분합니다.

## 검증 결과와 발견 사항

- 모든 연도에서 날짜 전체를 확보했고 `(SETTLEMENT_DATE, SETTLEMENT_PERIOD)` 중복은 0건입니다.
- 모든 컬럼의 빈 값 및 NA 계열 결측 표시는 0건입니다. 이것만으로 다른 컬럼의 0이 실제 측정값인지 미제공 표시인지까지 검증되었다는 뜻은 아닙니다.
- ND는 모든 행에서 유한한 양수로 확인됐습니다. 이 확인은 도메인상 모든 이상치가 없음을 보장하지 않습니다.
- 윤년인 2024년은 366일이므로 17,568행이며, 다른 해는 17,520행입니다.
- 각 연도에 46구간인 날과 50구간인 날이 하나씩 있습니다. 모두 서머타임 전환일과 일치하고, 구간 번호 누락이나 중복은 없습니다.
- 2022년은 `01-JAN-2022`, 2023년은 `01-Jan-23`, 2024년은 `01-JAN-2024`, 2025년은 `2025-01-01` 형태입니다. 처음의 날짜 파서로 읽지 못해 이 형식들을 명시적으로 지원하도록 수정했습니다. 원본 날짜 문자열은 변경하지 않았습니다.
- 2022년에는 `SCOTTISH_TRANSFER`가 없고 2023~2025년에는 있습니다. 전체 스키마는 같지 않지만 예측에 필요한 날짜·구간·ND 컬럼은 모든 해에 있습니다. 전처리 시 사용할 컬럼을 명시적으로 선택해야 합니다.

| 연도 | 46구간 날짜 | 50구간 날짜 |
| --- | --- | --- |
| 2022 | 03-27 | 10-30 |
| 2023 | 03-26 | 10-29 |
| 2024 | 03-31 | 10-27 |
| 2025 | 03-30 | 10-26 |

하루를 무조건 48행으로 가정하거나 날짜와 단순한 현지 시각만으로 중복 제거하면 정상 자료를 손실할 수 있습니다. 다음 전처리 단계에서는 현지 정산일을 Europe/London 시간대로 해석하고 UTC 기준 연속 30분 시간축으로 변환한 뒤 다시 간격을 검사합니다.

## 재현 파일

- `scripts/collect_data.py`: 공식 API에서 연도별 원본 주소 조회, CSV 다운로드 및 검증. Python 표준 라이브러리만 사용.
- `data/metadata/download_manifest.json`: 원본 URL, 리소스 ID, 다운로드 시각, SHA256, 파일 크기.
- `data/metadata/source_package.json`: 수집 시점의 공식 메타데이터 응답.
- `data/metadata/collection_audit.json`: 연도별 행·열·결측·중복·정산 구간 검증 결과.

`python scripts/collect_data.py --offline`으로 현재 스냅샷을 네트워크 연결 없이 다시 확인할 수 있습니다.
