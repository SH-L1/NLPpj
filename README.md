# 국민청원 데이터 기반 자연어 처리

청와대 국민청원 데이터를 활용해 장문 한국어 텍스트의 사회적 카테고리를 분류하는 자연어 처리 프로젝트입니다. 교재 수준의 RNN/LSTM 실습을 그대로 재현하는 데서 끝내지 않고, 로컬 개발 환경에서 데이터 수집, 정제, 베이스라인 모델링, KoBERT 파인튜닝, 성능 비교까지 이어지는 End-to-End 파이프라인을 구축하는 것을 목표로 합니다.

## 프로젝트 목표

- 약 4만 건 이상의 국민청원 CSV 데이터를 기반으로 장문 텍스트 분류 모델을 개발합니다.
- `인권`, `문화`, `육아` 등 사회적 카테고리를 예측하는 분류 태스크를 수행합니다.
- 머신러닝 앙상블 모델과 RNN/LSTM을 베이스라인으로 두고, KoBERT 기반 트랜스포머 모델의 성능 개선을 검증합니다.
- 단순 정확도뿐 아니라 Precision, Recall, F1-Score를 함께 측정하여 클래스 불균형 환경에서의 실질적인 분류 성능을 평가합니다.
- 목표 성능은 베이스라인 대비 유의미한 개선과 F1-Score 0.88 이상 달성입니다.

## 차별화 전략

### 1. 최신 NLP 모델 적용

교재의 RNN/LSTM 모델은 순차 처리 구조로 인해 긴 청원 본문에서 장기 의존성 문제가 발생할 수 있습니다. 본 프로젝트는 이를 비교군으로 활용한 뒤, 어텐션 메커니즘 기반의 KoBERT 모델을 파인튜닝하여 장문 한국어 문맥 분류 성능을 높이는 방향으로 설계합니다.

### 2. 로컬 환경 기반 파이프라인

Colab 의존도를 낮추고 Anaconda 기반 로컬 가상 환경에서 프로젝트를 수행합니다. 데이터 로드, 전처리, 토큰화, 학습, 평가가 한 환경에서 재현되도록 구성하여 실무형 개발 역량을 보여주는 것을 목표로 합니다.

### 3. 국민청원 도메인 맞춤형 전처리

국민청원 본문에는 분류에는 크게 기여하지 않지만 빈도가 높은 표현이 많이 포함됩니다. 예를 들어 `대통령님`, `청원합니다`, `부탁드립니다`, `간곡히` 같은 표현은 도메인 특화 불용어 후보로 관리합니다.

전처리 단계에서는 다음 기준을 적용합니다.

- HTML 태그, 특수문자, 이모티콘, 과도한 줄바꿈 제거
- 결측치 및 매크로성 중복 게시글 제거
- 사용자 정의 불용어 사전 구축
- `min_df`, `max_df` 조정을 통한 희귀 단어 및 과빈도 단어 제거
- 파라미터 선택 이유를 코드 주석과 보고서에 기록

### 4. 실험 재현성과 의사결정 기록

모델 간 비교가 공정하도록 `random_state`와 seed 값을 고정합니다. 또한 하이퍼파라미터, 불용어, 모델 선택 이유를 커밋 메시지, 코드 주석, 결과 보고서에 남겨 코드 유사도 검증과 발표 질의응답에 대비합니다.

## 전체 파이프라인

```text
채용 공고 분석
  -> 요구 역량 정의
  -> WBS 및 프로젝트 계획 수립
  -> 로컬 환경 구축
  -> 국민청원 데이터 수집 및 EDA
  -> 도메인 맞춤형 전처리
  -> 베이스라인 모델 학습
  -> KoBERT 파인튜닝
  -> 성능 비교 및 시각화
  -> 결과 보고서 및 발표 자료 작성
```

## 모델링 계획

| 구분 | 모델 | 목적 |
| --- | --- | --- |
| 비교군 1 | Random Forest / XGBoost 등 앙상블 모델 | 전통적 머신러닝 기준 성능 확보 |
| 비교군 2 | RNN / LSTM | 교재 기반 순환 신경망 성능 확인 |
| 실험군 | KoBERT | 트랜스포머 기반 장문 한국어 분류 성능 개선 |

## 평가 지표

| 지표 | 사용 이유 |
| --- | --- |
| Accuracy | 전체 예측 정답 비율 확인 |
| Precision | 특정 카테고리로 예측한 결과의 신뢰도 확인 |
| Recall | 실제 카테고리를 얼마나 놓치지 않았는지 확인 |
| F1-Score | Precision과 Recall의 균형 평가 |
| Confusion Matrix | 카테고리별 오분류 패턴 분석 |

## 실행 계획

### 1. 데이터 준비

```bash
python src/preprocess.py
```

- 원본 CSV 로드
- 결측치 및 중복 제거
- 정규표현식 기반 텍스트 정제
- 국민청원 도메인 불용어 제거
- 학습용/검증용/테스트용 데이터 분리

### 2. 베이스라인 학습

```bash
python src/train_baseline.py
```

- TF-IDF 기반 머신러닝 모델 학습
- RNN/LSTM 모델 학습
- 모델별 기본 성능 저장

### 3. KoBERT 파인튜닝

```bash
python src/train_kobert.py
```

- KoBERT 토크나이저 적용
- 국민청원 카테고리 분류용 fine-tuning
- seed 고정 후 실험 결과 저장

### 4. 성능 평가

```bash
python src/evaluate.py
```

- Accuracy, Precision, Recall, F1-Score 산출
- Confusion Matrix 시각화
- 베이스라인 대비 KoBERT 개선폭 비교

## 발표 준비 기준

- 코드 흐름을 파일 단위로 설명할 수 있어야 합니다.

- RNN/LSTM의 한계와 KoBERT 도입 이유를 장문 한국어 텍스트 관점에서 설명할 수 있어야 합니다.
